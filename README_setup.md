# みんなのおでかけ：自動備蓄セットアップ手順

所要時間の目安は 15 分です。プログラミングの知識は要りません。

## 全体の流れ

```
投稿者がフォーム送信
   ↓（自動）
Google Apps Script（Code.gs）
   ↓（自動で1行追加・最初は必ず非公開）
Googleスプレッドシート
   ↓  あなたが published のチェックを入れる／外す
公開データ（?action=public）→ おでかけナビ本体が読み込む
```

## 手順

### 1. スプレッドシートを作る
1. [Googleスプレッドシート](https://sheets.google.com) で「空白のスプレッドシート」を新規作成します。
2. 名前は自由です（例：`みんなのおでかけ 受付`）。

### 2. スクリプトを貼り付ける
1. メニューの **拡張機能 → Apps Script** を開きます。
2. 最初からある `function myFunction() {}` を全部消し、`Code.gs` の中身を丸ごと貼り付けます。
3. 保存（💾）します。

### 3. シートを準備する（1回だけ）
1. 上部の関数選択で **`setup`** を選び、**実行**を押します。
2. 初回は権限の確認が出ます。**「権限を確認」→ 自分のアカウントを選択 →「詳細」→「（プロジェクト名）に移動」→「許可」**の順に進みます。
   （自分で作ったスクリプトなので、「Googleで確認されていません」という表示が出るのは正常です）
3. スプレッドシートに `contributors` と `contributions` の2枚のシートができれば成功です。

### 4. ウェブアプリとして公開する
1. 右上の **デプロイ → 新しいデプロイ** を押します。
2. 歯車アイコンから種類を **ウェブアプリ** にします。
3. 設定は次のとおりです。
   - **次のユーザーとして実行**：自分
   - **アクセスできるユーザー**：**全員**
4. **デプロイ**を押し、表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

> 「全員」を選ぶのは、投稿者がログインなしで送信できるようにするためです。
> スプレッドシート自体は公開されません。外から見えるのは、あなたがチェックを入れた分だけです。

### 5. フォームにURLを設定する
1. `app.js` を開き、`const SUBMIT_API_URL = '';` の引用符の中に、手順4のURLを貼り付けます。
2. `index.html` と `app.js` を、GitHub のリポジトリ（creator.odekake-navi）にアップロードして置き換えます。

### 6. 動作確認
1. 公開ページからテスト投稿をします。
2. スプレッドシートの `contributions` に1行増え、`published` が**未チェック**なら成功です。
3. チェックを入れ、ブラウザで `（手順4のURL）?action=public` を開きます。チェックした投稿だけが JSON で表示されます（反映まで最大1分ほどかかります）。

## 毎日の運用

| やりたいこと | 操作 |
|---|---|
| 公開する | `contributions` シートの **published にチェックを入れる** |
| 非公開にする | チェックを外す |
| 不適切な投稿を消す | 行を削除する |

- 紹介者（`contributors` シート）の公開は自動です。公開投稿が1件以上ある人だけが公開データに含まれます。
- 同じInstagramアカウントの人は、別のブラウザから送っても同じ紹介者としてまとまります。
- `contributions` シートには、確認しやすいよう施設名や紹介者名も入ります。
- `published` 以外の列は、直接編集してもかまいません。コメントの誤字直しなどもできます。

## おでかけナビ本体を接続する

本体が今 `contributors.json` と `contributions.json` を読んでいる場合は、読み込み先を次のURLに変えるだけです。形式は従来と同じ配列です。

- 紹介者：`（手順4のURL）?action=contributors`
- 投稿：`（手順4のURL）?action=contributions`

まとめて取得する場合は、`app.js` の `ODEKAKE.fetchPublicData()` が使えます。

## こんなときは

- **送信できませんでしたと出る**
  - URLの貼り間違いか、デプロイの「アクセスできるユーザー」が「全員」になっていない可能性があります。
  - その場合でも、投稿者にはJSONのコピー／ダウンロード画面が出て、データは失われません。
- **Code.gs を修正したとき**
  - **デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン：新バージョン → デプロイ**の順に操作します。URLは変わりません。
  - 「新しいデプロイ」を選ぶとURLが変わってしまうので、避けてください。
- **既に公開している過去データがあるとき**
  - 既存の `contributions.json` などの内容を、シートの該当列に貼り付け、published にチェックを入れれば引き継げます。
  - JSON からの変換が必要でしたら、ご相談ください。
- **いたずら投稿が心配なとき**
  - 新規投稿は必ず非公開で始まるので、チェックしない限り表示されません。
  - 1分間に受け付ける件数の上限は `MAX_PER_MINUTE`（既定20件）で調整できます。
- **`admin.html` について**
  - 管理はスプレッドシートで行うため、不要になります。フォームからのリンクも外してあります。ファイル自体は残しても削除しても構いません。
